# Child Safety Vite Frontend

Vite + React frontend for the child safety tracker.

Run:
1. unzip the project
2. npm install
3. npm run dev
Open: http://localhost:5173

Notes:
- WebSocket helper expects STOMP/SockJS at http://localhost:8080/ws
- REST API baseURL in src/services/api.js is http://localhost:8080/api
